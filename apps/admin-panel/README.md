# Админ-панель (веб)

В версии 1.0 администрирование выполняется командами в боте:

| Команда | Что делает |
|---|---|
| `/stats` | пользователи, выручка, конверсия триала |
| `/user <tg_id>` | карточка пользователя |
| `/give <tg_id> <дней>` | выдать дни вручную |
| `/nodes` | состояние нод и последние инциденты |
| `/heal <код-ноды>` | ручной запуск восстановления |
| `/broadcast <текст>` | рассылка с троттлингом |

Этого достаточно примерно до 1000 пользователей.

## Когда понадобится веб-панель

Когда появятся: несколько администраторов, возвраты платежей, ручные
корректировки биллинга и графики. Бэкенд к этому уже готов — в
`apps/api-server/app/main.py` есть группа `/internal/*`, защищённая
заголовком `X-Internal-Token`.

Планируемый стек: React + Vite, обращение к `/internal/*`.
Эндпоинты описаны в `docs/API.md`.
