# Telegram Mini App — личный кабинет

Статическая страница, которую отдаёт API по адресу `/app`.
Файлы монтируются в FastAPI как `/static` (см. `apps/api-server/app/main.py`).

## Как подключить

В @BotFather: `/mybots` → бот → *Bot Settings → Menu Button* →
URL `https://<ваш-домен>/app`.

## Авторизация

Логинов нет: страница отправляет `Telegram.WebApp.initData` в заголовке
`X-Telegram-Init-Data`, сервер проверяет HMAC-подпись ключом бота.
Подделать запрос от чужого имени невозможно.

## Что показывает

- кольцо с остатком дней (цвет меняется: зелёный → жёлтый → красный);
- тариф, статус, дату окончания;
- устройства, трафик, серию продлений;
- персональный оффер с обратным отсчётом;
- кнопки: подключить, продлить, заморозить, «не работает», пригласить.

## Разработка

Сборка не нужна — это чистый HTML/CSS/JS. Правьте файлы и перезагружайте
страницу. Цвета берутся из темы Telegram, поэтому кабинет автоматически
поддерживает светлую и тёмную тему.
