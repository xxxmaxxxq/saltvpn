# 📋 Техническое задание — VPN-сервис v1.0

**Заказчик:** Maksim · **Дата:** 17.09.2026 · **Статус:** утверждено, в разработке

---

## 1. Цель и границы проекта

Создать коммерческий VPN-сервис с полностью автоматической продажей доступа через
Telegram-бота: пользователь нажимает «Попробовать», получает рабочий ключ за 10 секунд,
платит картой/СБП/криптой/звёздами и продлевается без участия человека.

**Целевая нагрузка v1.0:** 1000 активных подписчиков, приходящих постепенно.
**Не входит в v1.0:** собственные мобильные приложения, партнёрская B2B-программа,
мультиязычность (только русский), автоматический подбор нод по геолокации.

### 1.1 Роли

| Роль | Что делает |
|---|---|
| Гость | Запустил бота, ещё не активировал триал |
| Пользователь | Имеет активную/истёкшую подписку |
| Администратор | Смотрит статистику, выдаёт дни вручную, управляет нодами |
| Система | Воркеры: уведомления, списание дней, Auto-Healing |

## 2. Архитектура

### 2.1 Схема

```
[Пользователь] ─► [Telegram Bot] ─► [API-server] ─► [Marzban Master] ─► [Node NL / Node RU]
                        │                │                                      │
                        │                ├─► PostgreSQL (биллинг)               │
                        │                └─► Redis (FSM, кэш, антифрод)         │
                        └────────────── Deep link happ://import/<sub_url> ──────┘
```

### 2.2 Разделение серверов

| Сервер | Что стоит | Требования |
|---|---|---|
| **Master** (DE/FI) | Marzban-панель, PostgreSQL, Redis, бот, API, воркеры, Caddy | 2 vCPU / 4 GB / 40 GB SSD |
| **Node NL** 🇳🇱 | Marzban-node + Xray | 1–2 vCPU / 2 GB / канал 1 Гбит |
| **Node RU** 🇷🇺 | Marzban-node + Xray | 1–2 vCPU / 2 GB |

Мастер не пропускает через себя пользовательский трафик — только управление.
Это значит: блокировка IP ноды не роняет бота и биллинг.

### 2.3 Протоколы

| Приоритет | Протокол | Порт | Назначение |
|---|---|---|---|
| Основной | VLESS + Reality + XTLS-Vision | TCP/443 | 90% трафика, маскировка под чужой TLS |
| Резервный | Hysteria 2 | UDP/443 | мобильные сети, высокий packet loss |
| Запасной | Shadowsocks-2022 | TCP/8388 | простой фолбэк |

Reality не требует своего домена и сертификата — маскируемся под нейтральный
внешний SNI (список в `config/xray-vless/`).

## 3. Тарифы и лимиты

### 3.1 Тарифная сетка (`config/tariffs.yml`)

| Тариф | Локации | 1 мес | 3 мес (−10%) | 6 мес (−20%) | 12 мес (−35%) |
|---|---|---|---|---|---|
| 🇳🇱 Европа / Мир | NL | 149 ₽ | 402 ₽ | 715 ₽ | 1162 ₽ |
| 🇷🇺 Россия | RU | 199 ₽ | 537 ₽ | 955 ₽ | 1552 ₽ |
| 🌍 Мульти | NL + RU | 249 ₽ | 672 ₽ | 1195 ₽ | 1942 ₽ |

### 3.2 Лимиты

- **Триал:** 3 дня, все локации, один раз на Telegram ID.
- **Устройства:** 2 одновременных IP базово, максимум 5 (через рефералов).
- **Трафик:** безлимит (мягкий потолок 500 ГБ/мес с уведомлением админу).
- **Пауза:** до 30 дней в календарный год, минимум 1 день за раз.

### 3.3 Антифрод триала

Триал НЕ выдаётся, если: аккаунт Telegram моложе порога (эвристика по ID),
у этого же `telegram_id` триал уже был, или устройство/IP совпадает с
аккаунтом, уже бравшим триал (хэш IP в Redis, TTL 30 дней).

## 4. Функциональные требования

### 4.1 Онбординг (FR-01)

1. `/start` → приветствие + кнопка **«🎁 Попробовать 3 дня бесплатно»**.
2. Нажатие → создаётся пользователь в Marzban (`trial_<tg_id>`), выдаётся подписка.
3. Ответ содержит: кнопку **«⚡ Подключить в 1 клик»** (`happ://import/...`),
   кнопку «📱 Другое приложение», кнопку «📖 Инструкция».
4. Всё это — **без ввода карты и без запроса контактов**.

Целевая метрика: от `/start` до работающего VPN — менее 60 секунд.

### 4.2 Deep Linking (FR-02)

Ссылка-подписка: `https://<PUBLIC_BASE_URL>/sub/<token>`
Deep links, которые бот отдаёт кнопками:

- Happ: `happ://import/<subscription_url>`
- Hiddify: `hiddify://import/<subscription_url>`
- v2rayTun / Streisand: `v2raytun://import/<subscription_url>`

Определение платформы происходит в Mini App (по `navigator.userAgent`), в чате
бот показывает iOS/Android/Windows/macOS кнопками.

### 4.3 Платежи (FR-03)

Единый интерфейс `PaymentProvider` (см. `apps/api-server/app/payments/base.py`):

| Провайдер | Метод | Подтверждение |
|---|---|---|
| Platega | СБП, МИР, Visa/MC | webhook `POST /webhook/platega` + HMAC-подпись |
| CryptoPay | USDT/TON | webhook `POST /webhook/cryptopay` + HMAC-SHA256 |
| Telegram Stars | XTR | `pre_checkout_query` + `successful_payment` |

Требования:
- Идемпотентность: повторный вебхук с тем же `external_id` не начисляет дни дважды.
- Все платежи пишутся в таблицу `payments` со статусами `pending/paid/failed/refunded`.
- При успехе: продление подписки → пересчёт streak → начисление реферального бонуса → уведомление.

### 4.4 Умный биллинг и уведомления (FR-04)

Воркер `notifier` раз в 5 минут ищет подписки, которым пора отправить триггер:

| Триггер | Когда | Содержание |
|---|---|---|
| `trial_offer` | за 2 часа до конца **триала** | скидка 40% на первый месяц, таймер |
| `expire_3d` | за 3 дня | «осталось 3 дня», кнопка продлить |
| `expire_1d` | за 1 день | «остался 1 день» |
| `expire_2h` | за 2 часа | «осталось 2 часа», скидка 15% |
| `expired` | в момент истечения | «доступ отключён», оффер на возврат |
| `winback` | через 7 дней после истечения | скидка 30% на возврат |

Каждый триггер отправляется один раз (таблица `notifications`, уникальный
индекс `(subscription_id, kind)`).

### 4.5 Auto-Healing (FR-05) — ключевая фишка

**Проблема:** IP ноды попал в блокировку → у 1000 клиентов «перестал работать VPN» →
отток. У конкурентов лечится только перепиской с поддержкой.

**Решение:**

1. Воркер `health` каждые `HEALTH_CHECK_INTERVAL_SEC` (120 с) проверяет каждую ноду:
   TCP-хендшейк на боевой порт + опрос `/api/node/{id}` в Marzban + latency.
2. `HEALTH_FAIL_THRESHOLD` (3) провала подряд → статус ноды `degraded`.
3. Система выполняет **план восстановления** (по порядку, до первого успеха):
   - переключение inbound на **резервный SNI** из пула,
   - переключение на **резервный порт**,
   - активация **Hysteria 2** как основного протокола для этой локации,
   - переключение пользователей на **резервную ноду** той же локации (если есть).
4. Конфиги в Marzban обновляются, **ссылка-подписка у клиента не меняется**.
5. Всем затронутым пользователям уходит пуш: «⚡ Мы уже переключили вас на резервный
   канал. Если приложение не подхватило — нажмите «Обновить подписку»».
6. Админу — отдельное уведомление с деталями и предложением заказать новый IP.

**Кнопка «🆘 Не работает»** в боте запускает ту же процедуру персонально: меняет
пользователю inbound на резервный, отдаёт обновлённый deep link и предлагает
альтернативное приложение. Тикет в поддержку создаётся, только если это не помогло.

### 4.6 Пауза подписки (FR-06)

- Кнопка «⏸ Заморозить» доступна при активной платной подписке (не на триале).
- Пользователь выбирает срок 1–30 дней; дни подписки **не списываются**.
- В Marzban пользователь переводится в статус `disabled` (трафик не идёт).
- Автоматическая разморозка воркером + уведомление. Досрочная — кнопкой.
- Лимит — 30 дней в календарный год, остаток виден в Mini App.

### 4.7 Streak-бонусы (FR-07)

- Продление **до момента истечения** (или в течение 24 ч после) увеличивает `streak_count`.
- Бонус за продление: `min(streak_count, 7)` дней сверху.
- Разрыв более 24 ч → `streak_count = 0`.
- В Mini App — прогресс-бар «🔥 Серия: 4 продления · следующее +5 дней».

### 4.8 Рефералы на слотах устройств (FR-08)

- У каждого пользователя своя ссылка `https://t.me/<bot>?start=ref_<code>`.
- Приглашённый засчитывается **только после первой оплаты** (не за триал).
- Каждые **2 оплативших** реферала = **+1 постоянный слот устройства** (max 5 всего).
- Реферер получает уведомление, приглашённый — 3 бонусных дня к первой оплате.
- Защита: нельзя пригласить самого себя, нельзя переназначить реферера.

### 4.9 Telegram Mini App (FR-09)

Экран личного кабинета: остаток дней (кольцевой индикатор), тариф и локации,
трафик за месяц, занятые/доступные слоты устройств, streak, остаток дней паузы,
кнопки: продлить, сменить тариф, заморозить, скопировать подписку, «Не работает».

Авторизация — по `Telegram.WebApp.initData` с серверной проверкой HMAC-подписи
(без собственных логинов и паролей).

### 4.10 Админ-функции (FR-10)

Команды в боте для `ADMIN_IDS`: `/stats` (юзеры, выручка, конверсия триала,
активные подписки), `/user <tg_id>` (карточка), `/give <tg_id> <дней>`,
`/broadcast` (рассылка с подтверждением), `/nodes` (статус нод и ручной heal).

## 8. Риски и их снятие

| Риск | Вероятность | Митигация |
|---|---|---|
| Блокировка IP ноды РКН | Высокая | Auto-Healing + пул резервных SNI/портов + запасной IP |
| Блокировка бота в Telegram | Средняя | Резервный бот + инфо-канал, база на своём сервере |
| Отключение RU-ноды хостером | Средняя | Хостер с лояльным ToS, готовый скрипт переезда за 15 минут |
| Отвал платёжного шлюза | Средняя | 3 независимых провайдера, абстракция `PaymentProvider` |
| Утечка БД | Низкая | Нет паролей и приватных ключей в БД, бэкапы шифруются |
| Шеринг ключей | Высокая | Лимит IP на уровне Xray + мониторинг аномалий |

## 9. Критерии приёмки v1.0

- [ ] Новый пользователь получает рабочий VPN за < 60 с без оплаты.
- [ ] Оплата всеми тремя способами продлевает подписку автоматически.
- [ ] Повторный вебхук не начисляет дни дважды.
- [ ] Отключение ноды в тесте приводит к автопереключению за < 5 минут.
- [ ] Пауза/разморозка, streak и реферальные слоты считаются корректно.
- [ ] Mini App открывается и показывает актуальные данные.
- [ ] `docker compose up -d` поднимает весь стек с нуля.
- [ ] Тесты и линтер в CI зелёные.
